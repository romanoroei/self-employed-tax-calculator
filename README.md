# מחשבון הטבות מס לעצמאים

מחשבון משולב לתכנון הפקדות לפנסיה ולקרן השתלמות ולחישוב אומדן הטבות המס לשנים 2024–2026.

פותח עבור רועי רומנו — מתכנן פיננסי.

היישום נמצא בקובץ index.html וניתן להפעיל אותו ישירות בדפדפן. החישובים מקומיים. המידע נועד להמחשה ולתכנון ראשוני ואינו מחליף חישוב מס אישי. פרטי ההנחות, הגילוי הנאות, מדיניות הפרטיות והצהרת הנגישות מופיעים באתר.

## מדידת שימוש — Google Analytics 4

- חשבון קיים: GemelHub, מזהה 400008382.
- נכס נפרד: מחשבון הטבות מס לעצמאים, מזהה 561020571.
- מקור נתוני אתר: 16214363704; מזהה מדידה: G-9GFDYS61G9.
- כתובת ניהול: https://analytics.google.com/analytics/web/#/a400008382p561020571/admin
- קובץ המדידה: analytics.js. הוא נטען אחרי קוד המחשבון.

Google נטען רק לאחר אישור מדידה. לפני אישור, לאחר דחייה ובתצוגות מקומיות לא נטען תג Google ולא נשלחים אירועי מדידה. העדפה נשמרת ל־180 ימים; אפשר לשנותה דרך „עוגיות”. עוגיות המדידה מוגבלות לנתיב האתר ומשתמשות בקידומת pensioncalc כדי לא לשנות עוגיות של פרויקטים אחרים באותו דומיין.

המדידה המשופרת במקור הנתונים כבויה. אין מדידת שדות או טפסים אוטומטית. אין להוסיף לאירועים הכנסה, הפקדות, תוצאות כספיות, פרטי קשר, תוכן הודעות או כתובות של קישורי יצירת קשר. כתובת הדף מצומצמת לקישור הקבוע ותגיות UTM תקינות בלבד; המקור המפנה מצומצם לדומיין.

| אירוע | משמעות |
| --- | --- |
| page_view | צפייה אחרי אישור מדידה |
| calculation_complete | חישוב מוצלח של הטופס הראשי; עריכה אוטומטית אינה נספרת כחישוב חדש |
| contact_click | לחיצה על WhatsApp, טלפון או קישור מייל ישיר |
| contact_email_open | פתיחת חלון המייל באתר |
| contact_email_compose | הכנת הודעה לתוכנת הדואר לאחר אימות הפרטים והאישור |
| benefit_breakdown_view | צפייה בפירוט סל ההטבות המוצג פתוח, פעם אחת בכל חישוב ורק לאחר אישור מדידה |
| service_details_open | פתיחת „מה כולל השירות?” |
| calculator_share | לחיצה על שיתוף המחשבון |

מאפייני אירוע מוגדרים בדוחות: cta_location (comparison / page_end / footer), contact_channel (whatsapp / phone / email).

האירועים contact_click ו־contact_email_compose מוגדרים כאירועים מרכזיים, פעם אחת בכל סשן וללא ערך כספי ברירת מחדל.

לחיצה על WhatsApp, טלפון או פתיחת תוכנת הדואר אינן הוכחה שהתקבלה פנייה. לא נשלח generate_lead. קבלת פנייה, התאמה, שיחה והצטרפות דורשות מעקב עסקי נוסף.

בדיקות: `node --test tests/analytics.test.cjs tests/pension.test.cjs`.

עדכון 27.10.2026: נוסח העוגיות פשוט ומזמין, עם בחירה מפורשת ושוות נראות. פרטי הסוכן, גילוי נאות, פרטיות, נגישות ושינוי העדפות עוגיות זמינים גם לפני החישוב הראשון. אין להסיק מהבדיקות הטכניות אישור לעמידה מלאה בכל חובות הרישוי והנגישות. השלמת רשימת הגופים בעלי הזיקה, מהות הזיקה והסדרי קבלת קהל תלויה בפרטי העסק.

פירוט סל ההטבות מוצג תמיד לאחר חישוב, כשלב 03. אירוע benefit_breakdown_open הוחלף ב־benefit_breakdown_view; אירוע צפייה נשלח רק כש־10% ממקטע הפירוט נראים בפועל.

מגבלות הזנה: הכנסה שנתית עד 10,000,000 ₪ והפקדה אישית עד 499,999 ₪ לכל מוצר, בכל אחת משתי הטבלאות. סכום תקין שעובר את התקרה בזמן הקלדה או הדבקה נחתך לתקרה, וגם אימות החישוב אוכף את הטווח. בנייד מקש המשך/Enter בשדה ההכנסה מעביר לכפתור החישוב; רק לחיצה על הכפתור מפעילה חישוב וגלילה לתוצאות.
